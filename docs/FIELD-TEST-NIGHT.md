# 밤 실측 — 자는 동안 알람이 뜨는가

**한 번도 안 해 봤다.** 7월 말 Guard v1이 선 뒤로 계속 밀렸다.

---

## 무엇을 확인하나

**Doze 상태에서 `setAlarmClock`이 실제로 기기를 깨우는가.**

Guard의 발동 경로 둘 중 A(시각·보호 규칙)가 그것에 전부 걸려 있다.
낮에는 화면이 켜져 있어 확인이 안 된다 — **Doze는 화면이 꺼지고 움직임이 없어야 들어간다.**

그리고 이 실패는 **아무 오류도 내지 않는다.** 알림이 안 뜨는 것으로만 드러나고,
그때는 이미 그 밤이 지났다. 9~11월 실사용이 §6.5의 전례를 쌓는 기간인데
**그 전제가 바로 이것**이다.

## 하네스로 대체되지 않는다

`dumpsys deviceidle force-idle`은 흉내다. 실제 Doze와 다를 수 있고,
제조사(삼성) 최적화는 그 위에 한 겹 더 있다. **하룻밤이 필요하다.**

---

## 준비 — 자기 전 10분

### ① 발동이 예약되게 만든다

내일 **09:00 일정**을 하나 만들고 보호를 켠다. 기본값이면 자동으로 이렇게 예약된다:

```
데드라인 = 09:00 − 준비 90분 − 수면 360분 = 01:30

01:30      Level 3   "지금 자야 합니다"
02:00~     Level 4   30분 간격 6회 (05:00까지)
```

**03:00 언저리에 Level 4가 두세 번 온다** — 그것이 이 실측의 과녁이다.

### ② 서버가 예약을 만들었는지 본다

```cmd
node test/device.mjs "JSON.stringify((await Api.guardSchedule()).plans[0].fires.map(f=>f.at))"
```

01:30·02:00·02:30… 이 나와야 한다. **안 나오면 여기서 멈춘다** — 밤을 기다릴 필요가 없다.

### ③ 기기가 알람을 걸었는지 본다

```cmd
node test/device.mjs "await Capacitor.Plugins.Guard.state()"
```

권한 넷이 `true`인지 먼저 본다. 하나라도 `false`면 그것부터다.

```cmd
adb shell dumpsys alarm | findstr /i "personalos"
```

`setAlarmClock`으로 걸린 것이 보여야 한다. **`RTC_WAKEUP`이 아니면 Doze가 미룬다.**

### ④ 폰을 두고 잔다

```
□ 충전기를 꽂지 않는다        ← 충전 중이면 Doze가 안 걸린다. 시험이 무의미해진다
□ 화면을 끄고 손대지 않는다   ← 움직이면 Doze에서 나온다
□ 방해 금지를 켜도 된다       ← ADR-026 — 무음을 override하지 않는 것도 함께 확인된다
□ USB를 뽑는다               ← 연결돼 있으면 충전이다
```

## 아침에

### 무엇이 남았나

```cmd
node test/device.mjs "JSON.stringify((await Api.guardEvents()).slice(0,8).map(e=>[e.fired_at,e.level,e.cause,e.reaction]))"
```

01:30~05:00 사이 `protect:` 계열이 몇 건 있는지 본다.

### 가르는 표

| 남은 것 | 뜻 | 다음 |
|---|---|---|
| 예약대로 다 있다 | **통과.** Doze를 통과한다 | 9월 준비 끝 |
| 일부만 있다 | Doze가 일부를 미뤘다 | 몇 시 것이 빠졌나 — 깊은 Doze는 시간이 갈수록 창이 넓어진다 |
| 하나도 없다 | 알람이 안 울렸거나 기록이 안 갔다 | 아래 ③으로 |
| 알림은 봤는데 기록이 없다 | 발동은 됐고 **동기화가 실패** | `G.flushEvents()` · 오프라인 큐 |

### ③ 하나도 없을 때

```cmd
adb shell dumpsys deviceidle
adb shell dumpsys alarm | findstr /i "personalos"
```

- `deviceidle`이 `IDLE`까지 갔는가 — 안 갔으면 실험 자체가 성립 안 했다
- 알람이 아직 걸려 있는가, 아니면 사라졌는가
- **삼성 절전**: 설정 → 배터리 → 백그라운드 사용 제한에 앱이 들어갔는지

**폰을 만지기 전에 이 둘을 먼저 뽑는다.** 화면을 켜면 Doze에서 나오고 증거가 흐려진다.

## 기록

결과는 `STATE.md` §미해결이 아니라 **`APP-BUILD.md` 결정 기록**에 남긴다 —
"확인했다"가 아니라 **"어느 조건에서 어떻게 됐다"**를 적는다.
9월에 문제가 나면 그때 이 기록과 비교한다.

실패했다면 **무엇을 바꿔서 다시 잘 것인지**까지 적는다. 한 번 자고 끝날 일이 아닐 수 있다.
