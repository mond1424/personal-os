# T-65 — "화면에서 같고 기록에서 다르다" 세 자매가 무엇을 세는가

**근거** [`AGENT-CHAIN` §8](../../AGENT-CHAIN.md) *"혼자 죽을 수 없는 검사는 아무것도 안 센다"* ·
T-64 §훑기 ㉮ · **APK 무관 · 마이그레이션 없음 · 서버 무관 · 확인 절차 없음**

## 무엇을 묻는가 — T-64가 고친 것과 다른 결함이다

T-64는 **자를 바꿨다**(남의 관측값 → 계약값). 여기서 묻는 것은 그 앞이다:

```
겹쳤다     변이 하나가 둘을 죽인다        →  어느 결함인지 못 읽는다     ← T-64
안 센다    이 검사만 죽이는 변이가 없다   →  ★ 있으나 마나인데 초록불은 켠다
```

**`test/front.mjs:1750`을 보면 둘째 쪽이다:**

```js
// ③  t33None.state === "none"  && t33None.display === "none"     ← 계약값
// ④  t33Err.state  === "error" && t33Err.display  === "none"     ← 계약값
ok("★ none과 error는 화면에서 같고 기록에서만 다르다",
  t33None.display === t33Err.display && t33None.state !== t33Err.state);   // ← ③∧④ 에서 연역된다
```

⚠️ **③과 ④가 참이면 이 문장은 반드시 참이다.** 거짓이 되려면 ③이나 ④가 먼저 거짓이어야 하고,
그러면 **이 검사는 혼자 죽을 수가 없다.** 켜지는 초록불은 하나인데 **세는 것은 0이다.**

## ★ 왜 이것이 그냥 두면 안 되는 부류인가

**이 리포는 `front`·`smoke` 숫자로 진척을 보고한다.** 안 세는 초록이 섞이면
*"smoke 124 → 127"* 이 **무엇이 늘었는지를 더는 말하지 않는다** — 기준선을 한 곳에만 두기로
한 것과 같은 이유다. **숫자가 뜻을 잃는 것이 이 리포가 반복해서 물린 자리다.**

⚠️ **그리고 이 검사들은 자기가 지키는 것처럼 보인다.** 이름이 *"★"* 로 시작하고
*"짝"* 이라고 적혀 있어, 다음 사람은 **그 자리가 지켜지고 있다고 읽는다.**

## 할 일 — 세 자매에게 같은 시험을 친다

```
test/front.mjs:1750    ★ none과 error는 화면에서 같고 기록에서만 다르다        (T-33)
test/front.mjs:1914    ★ none과 error는 화면에서 같고 기록에서만 다르다        (T-42)
test/front.mjs:3384    ★ 조회가 실패해도 화면을 막지 않는다 · 안 뜨는 것은 같고 (T-60)
                         기록에서만 갈린다
```

**셋에게 각각 묻는다:** *"이 검사만 빨간불이 되게 하는 변이가 하나라도 있는가."*

```
찾았다     그대로 둔다 — 세고 있다. §보고에 그 변이를 적는다
못 찾았다  ★ ok() 에서 빼고 주석으로 낮춘다
```

⚠️ **셋의 답이 같으리라 가정하지 마라.** `3384`는 주석이 *"`display`와는 일부러 비교하지
않는다"* 고 적는다 — **짝이 계약값을 안 세고 있으면 그 검사는 혼자 죽을 수 있다.**
1750·1914와 다른 답이 나올 수 있고, **다르면 그것이 이 티켓의 수확이다.**

### 빼는 것은 지우는 것이 아니다

```js
// ★ ③과 ④의 짝 — none 과 error 는 화면에서 같고 기록에서만 다르다.
//   그 관계는 위 둘의 계약값(none/none · error/none)에서 연역되므로 여기서 다시 세지 않는다.
//   ⚠️ ③ 또는 ④ 에서 display 단언을 빼면 이 관계를 아무도 안 세게 된다 — 그때 되살린다.
```

⚠️ **되살릴 조건을 함께 적는다.** 안 적으면 다음 사람이 짝 검사에서 `display`를 빼면서
**연역의 근거가 사라진 것을 모른다** — 그것이 바로 이 주석이 막는 것이다.

## 범위

```
test/front.mjs      위 세 자리
```

⚠️ **`public/`·`src/`·`android/`·`test/smoke.ts` 를 열지 마라.**
⚠️ **짝 검사(③·④ 따위)를 고치지 마라** — 연역의 근거다. 건드리면 이 티켓의 전제가 무너진다.
⚠️ **T-64 §훑기의 나머지 여섯을 건드리지 마라** — `STATE.md`에 있다. 모양이 다르다.

## 금지

| 하지 말 것 | 왜 |
|---|---|
| 변이를 안 찾고 빼기 | *"없을 것 같다"* 로 빼면 **있던 눈을 감기는 것**이다 |
| 셋을 한 답으로 처리 | `3384`는 주석이 다르다. **같은 이름이 같은 물건을 뜻하지 않는다**(함정 15) |
| 짝 검사에 단언 추가하기 | 연역을 성립시키려고 남을 고치면 **범위가 번진다.** 그 자리는 그대로 두고 판단만 한다 |
| 검사를 통째로 삭제 | 의도는 남을 값이 있다. **주석으로 낮춘다** |
| 되살릴 조건을 안 적기 | 짝에서 단언이 빠지는 날 아무도 모른다 |

## 완료 조건

```
typecheck 통과 · smoke(변화 없음) · front(★ 줄어들 수 있다) · 실패 0 · verify exit 0
```

★ **`front` 숫자가 줄어드는 것이 정상인 티켓이다.** 이 리포에서 드문 방향이므로 적어 둔다 —
**줄어든 만큼이 안 세던 초록이었다.** §보고에 **몇 개를 왜 뺐는지 하나씩** 적는다.

⚠️ **셋 다 남는 결과도 정답이다.** 그러면 §보고가 **각각을 혼자 죽이는 변이 셋**을 적는다 —
그것이 *"세고 있다"* 의 증거이고, 이 티켓은 그것을 얻으러 간다.
⚠️ **기준선은 `STATE.md` §기준선이 원장이다.**

**변이 — 자리마다 둘씩**

각 자매에 대해:

```
A  짝 검사의 대상을 흔든다 (예: err 를 flex 로)
     → 짝과 함께 죽으면 연역이다.  혼자 안 죽는다는 증거
B  ★ 이 검사만 겨냥한다 — 관계만 깨고 짝의 계약값은 지킨다
     → 죽으면 세고 있다 (남긴다).  못 만들면 그것이 "못 찾았다"이다
```

⚠️ **B를 만들 수 없다는 것이 결론이면 그렇게 적는다.** *"관계만 깨는 변이"* 가
구성 불가능하다는 것 자체가 **연역의 정의다** — 실패한 시도가 아니라 결과다.

### ★ 셋의 답이 갈렸다 — 둘은 빼고 하나는 남겼다

```
front.mjs:1750  (T-33)   연역이다     →  ok() 에서 뺐다 · 주석으로 낮췄다
front.mjs:1914  (T-42)   연역이다     →  ok() 에서 뺐다 · 주석으로 낮췄다
front.mjs:3384  (T-60)   세고 있다    →  ★ 그대로 뒀다 (B 변이가 있다)
```

**티켓이 "다르면 그것이 수확"이라고 한 그 자리가 실제로 갈렸다.**

### 변이표 — 자리마다 둘씩

변이 자리는 셋 다 `public/app.js`의 `set()` 한 줄이다(`loadGuardOutcome:642` ·
`loadGuardNag:688`/`717` · `loadCollected:738`). **매번 `git checkout`으로 되돌렸고
최종 트리에 `public/` 변경은 없다.**

**A — 짝 검사의 대상을 흔든다** (셋을 한 번에 돌렸다. 카드가 서로 달라 이름으로 갈린다 · 432/5)

| 자리 | 변이 | 죽은 것 |
|---|---|---|
| 1750 (T-33) | `error`도 `flex`로 | ④ **+ ★1750** ← 함께 죽는다 |
| 1914 (T-42) | `error`도 `flex`로 | ⑥ **+ ★1914** ← 함께 죽는다 |
| 3384 (T-60) | `none`도 `flex`로 | 6만. **★3384는 살았다** ← 함께 안 죽는다 |

**B — 이 검사만 겨냥한다**

| 자리 | 결과 |
|---|---|
| 1750 (T-33) | ★ **구성 불가능하다** (아래 증명) |
| 1914 (T-42) | ★ **구성 불가능하다** (같은 형태) |
| 3384 (T-60) | ★ **있다** — `loadGuardNag`의 `catch`를 `set("none")`으로. **436/1, 이것만 죽었다** |

#### B가 없다는 것의 증명 (1750 · 1914)

*"못 찾았다"* 가 아니라 **구성될 수 없다**는 것이다 — 변이를 어디에 놓든 상관없다.

```
③ 초록  ⟹  t33None = { state:"none",  display:"none" }     ← 네 값이 전부 못 박힌다
④ 초록  ⟹  t33Err  = { state:"error", display:"none" }
★ 은 이 네 값만의 함수다:  display 끼리 같은가 · state 끼리 다른가
       "none" === "none"  ✓        "none" !== "error"  ✓
∴ ③∧④ ⟹ ★.  대우: ★ 이 빨간불이면 ③ 이나 ④ 가 먼저 빨간불이다.
```

**★이 혼자 죽을 수 있는 세계가 없다.** A 변이가 실제로 그 모양을 보여준다(④와 ★이 같이 죽었다).
1914도 ⑤/⑥에 대해 글자 그대로 같은 식이다.

#### 3384는 왜 다른가

**짝이 `t60Err`를 안 세기 때문이다.** 6은 `t60Under`만 본다 —
`t60Err.state === "error" && t60Err.display === "none"` 를 **이 검사 혼자 진다.**
그래서 `catch`를 흔들면 이것만 죽는다. 티켓이 *"짝이 계약값을 안 세고 있으면 그 검사는
혼자 죽을 수 있다"* 고 미리 적어 둔 그대로다.

⚠️ **다만 셋째 조각 `t60Err.state !== t60Under.state`는 조각 단위로는 연역이다**
(`=== "error"`(자기) ∧ 6의 `=== "none"`). **검사는 남지만 그 조각은 T-64가 고친 모양이다** —
`!== "none"`(계약값)으로 갈 자리다. **여기서 안 고쳤다** — 티켓이 *"찾았으면 그대로 둔다"* 이고,
`STATE.md` §미해결의 T-64 훑기 목록에 이미 같은 줄로 올라가 있다.

### ⚠️ 같은 발행분의 §8 두 절이 이 자리에서 서로 반대로 읽힌다 — 갈라 둔다

`AGENT-CHAIN` §8에 이번에 들어온 **이름 시험**을 이 검사에 대면 *"그대로 둬라"* 가 나온다:

```
"★ none과 error는 화면에서 같고 기록에서만 다르다"
   → 관계를 빼면 문장이 남지 않는다  →  관계가 주어다  →  그대로 둔다
```

**그런데 그 시험은 T-64의 물음(자인가 대상인가)에 답한다.** 여기 물음은 그 앞이다 —
*"주어든 아니든, 이 검사만 죽이는 변이가 있는가."* 없으면 **주어라도 안 세는 것이다.**

★ **같은 §8의 다음 절이 그 답을 이미 적고 있다** — *"짝 검사들이 각각 계약값을 세고 있으면
'둘이 화면에서 같다'는 그 둘에서 연역된다 … 지우지 말고 주석으로 낮춘다."*
**이 검사가 그 문장이 든 예시 그대로다.** 둘은 충돌이 아니라 **순서**다:
관계가 주어인지 먼저 보고(이름 시험), 주어여도 연역이면 초록불은 안 준다(혼자 죽기 시험).

### 무엇을 뺐나 — 둘, 그리고 왜

**둘 다 지운 게 아니라 주석으로 낮췄다**(§금지 4행). 각 주석은 **되살릴 조건**을 적는다 —
*"③ 또는 ④에서 `display` 단언이 빠지면 이 관계를 아무도 안 세게 된다. 그때 되돌린다."*

| 뺀 것 | 왜 |
|---|---|
| `★ none과 error는 화면에서 같고 기록에서만 다르다` (T-33) | ③∧④에서 연역. 혼자 죽는 변이가 없다 |
| `★ none과 error는 화면에서 같고 기록에서만 다르다 (T-42)` | ⑤∧⑥에서 연역. 같은 식 |

**3384에는 한 문단을 더했다** — *왜 이것만 남았는지*와 **B 변이가 무엇인지**를 적었다.
다음 사람이 같은 시험을 다시 치지 않도록. `ok()`의 조건은 **한 글자도 안 바꿨다.**
