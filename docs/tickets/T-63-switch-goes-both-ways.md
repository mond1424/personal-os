# T-63 — 끈 것을 켤 수 있어야 한다

**발행** Cowork · 2026-09-07 · **담당** Claude Code · **작음**
**근거** [ADR-047 ③](../../APP-ADR.md#adr-047) *"끈 것은 켤 수 있어야 한다"* · **APK 무관 · 마이그레이션 없음**

---

## 무엇이 어긋났나 — 사용자가 껐고, 돌아오는 길이 없다

**2026-09-07 사용자:**

> 밤 L2가 꺼져있음 — **설정에서 다시 켤 방법을 못찾겠음**

```
끄기      나그 카드의 [끄기]                    있다   app.js  loadGuardNag()
켜기      ★ 앱 어디에도 없다                     없다
꺼졌음    ★ 화면 어디에도 안 적힌다              없다
```

⚠️ **끄기 토스트가 없는 자리를 가리킨다:**

```js
toast("밤 알림을 껐어요 — 설정에서 다시 켤 수 있어요");   // ← 그 설정이 없다
```

**스위치는 기기 prefs의 `watch_enabled` 하나이고**(`GuardSettings`), 그것을 만지는 UI는
나그 카드의 `setWatch({ enabled: false })` **한 방향뿐이다.**

## ★ 한 방향만 있는 문은 이탈 경로가 아니라 낭떠러지다

**T-60 §금지의 마지막 줄은 *"끄는 선택지를 안 주기"* 였다. 그 거울을 안 봤다.**

ADR-026의 *"이탈 경로에는 대가가 있지만 막지는 않는다"* 는 **돌아올 수 있을 때** 성립한다.
돌아올 수 없으면 선택이 아니라 사고이고, **한 번의 오탭이 Guard L2를 영구히 끈다.**

⚠️ **그 뒤의 침묵은 공강 밤의 침묵과 화면에서 구별되지 않는다** — T-60 ③이
*"결함이 조용해진다"* 를 막으려고 갈랐던 그 모양인데, **이번엔 사용자 자신의 선택이 조용해졌다.**

## 할 일 — 줄 하나. 새 패턴을 만들지 않는다

### ① 설정에 상태를 말하는 줄을 둔다

**`calStatusRow`(T-55) · `placeStatusRow`(T-59)와 **같은 모양**이다** — 셋째 자매다.

```
밤 알림          켜짐 ›        watchStatus().enabled === true
밤 알림          꺼짐 ›        false
밤 알림          앱에서만 돼요   플러그인 없음 (웹)
```

⚠️ **읽는 값은 이미 있다** — `GuardWatch.status()`가 `enabled`를 넣어 준다(`guard/GuardWatch.kt`).
**네이티브를 고치지 마라. 그러면 APK가 든다.**

### ② 켜고 끄는 것이 **같은 줄**에서 된다

**끄는 길을 여기서도 여는 이유는 ADR-047 ③이다** — 끌 수 없는 알림은 OS에서 무음 처리되고,
그러면 개입뿐 아니라 **관측도 잃는다.** 나그 카드는 *"무시가 쌓였을 때"* 의 입구로 그대로 둔다.

⚠️ **꺼짐은 실패가 아니라 선택이다 — 경고색(`srow-alert`)을 쓰지 마라.**
`calStatusRow`가 그것을 쓰는 것은 사용자가 **고쳐야 할** 상태이기 때문이다. 여기는 아니다.

### ③ 웹에서는 못 한다고 말한다

```
플러그인 없음   "앱에서만 돼요"      ← calStatusRow 의 off 와 같은 말
```

⚠️ **조용히 성공한 척하지 마라.** 나그 카드가 이미 이 자리를 옳게 지킨다
(`if (!G || !G.setWatch) return void toast(...)`) — **같은 판단을 여기서도 한다.**

## 범위

```
public/app.js        watchStatusRow · S.watchStatus 적재 · 토스트 문구가 가리키는 자리
test/front.mjs       검사
```

**마이그레이션 없음 · APK 무관 · 서버 무변경.**

⚠️ **`android/` 를 열지 마라** — `enabled`는 이미 `watchStatus`가 준다.
⚠️ **서버 `settings`에 스위치 키를 만들지 마라** — 아래 §금지 1행.
⚠️ **나그 카드(`loadGuardNag`)의 판정·임계를 건드리지 마라** — T-60의 몫이다. 여기는 줄 하나다.

## 금지

| 하지 말 것 | 왜 |
|---|---|
| 서버 `settings`에 스위치 키 만들기 | **두 벌이 된다.** 발동 경로엔 네트워크가 없다(ADR-021) — 기기 prefs 가 유일한 스위치다 |
| `android/` 수정 | `enabled`는 이미 온다. 고치면 APK가 들고 이 티켓이 커진다 |
| 꺼졌을 때 줄을 숨기기 | **꺼진 것을 못 읽는 것이 지금의 결함이다** |
| 꺼짐에 경고색 | 실패가 아니라 선택이다. 색을 쓰면 다음에 `calStatusRow`의 뜻이 흐려진다 |
| 토스트 문구만 고치고 자리를 안 만들기 | 약속을 지우는 것이 아니라 낮추는 것이다 |
| 플러그인 없을 때 켠 척하기 | 나그 카드가 이미 옳게 하는 것을 여기서 뒤집는다 |

## 완료 조건

```
typecheck 통과 · smoke(변화 없음) · front +N · 실패 0 · verify exit 0
```

⚠️ **기준선은 `STATE.md` §기준선이 원장이다.**
⚠️ **`smoke`가 움직이면 서버를 건드린 것이다** — 그때는 멈추고 보고한다.

**검사**

```
1  ★ enabled=false 면 줄이 "꺼짐"으로 보인다
2  ★ enabled=true  면 "켜짐"으로 보인다              ← 1의 짝
3  ★ 줄을 누르면 setWatch({enabled:true}) 가 불린다
4  ★ 켜진 줄을 누르면 setWatch({enabled:false}) 가 불린다   ← 3의 짝. 두 방향
5  ★ 플러그인이 없으면 안 부르고 그렇게 말한다        ← 조용한 성공이 없는가
6  ★ 꺼짐에 srow-alert 가 안 붙는다
7  서버 settings 에 스위치 키가 없다 (스캐너 — 두 벌 방지)
```

**3·4가 이 티켓의 본체다** — *"한 방향뿐"* 이 결함이었으므로 **두 방향이 다 세어져야 고쳐진 것이다.**

⚠️ **3·4가 줄을 찾을 때 `id`로 찾지 마라 — 화면에 보이는 글자로 찾아라**(함정 15).
`id`로 찾으면 **검사와 구현이 같은 이름을 공유해**, 그 이름이 틀렸을 때 양쪽이 함께 틀린다.
T-55에서 캘린더 12개가 숨은 칸에 쓰였는데 검사가 초록이던 것이 정확히 그 모양이다.

⚠️ **검사 신호에 토스트나 `until`을 쓰지 마라**(함정 14).

**변이**
- 줄을 안 그린다 → **1·2·3·4** 죽는다 (포함 관계 — 줄이 없으면 누를 것도 없다)
- 항상 "켜짐" → **1만** 죽는다
- 켜기만 되고 끄기가 안 된다 → **4만** 죽는다
- 플러그인 없이도 부른다 → **5만** 죽는다
- 꺼짐에 경고색 → **6만** 죽는다
- 서버 키를 만든다 → **7만** 죽는다

⚠️ **첫 변이가 넷을 죽이는 것은 예상이다** — 나머지 다섯이 하나씩 죽는 것이
검사들이 서로 다른 것을 센다는 증거다. **하나씩 안 죽으면 좁혀라**(T-60이 두 자리를 그렇게 좁혔다).

## 확인 절차 (사용자)

```powershell
npm run deploy
```

**APK 불필요 · 재설치 불필요** — 웹만이다.

```
□ 설정에 "밤 알림" 줄이 보이고, 지금 상태가 꺼짐이라고 적혀 있다
□ ★ 눌러서 켜면 줄이 "켜짐"으로 바뀐다
□ ★★ 그날 밤 L2 가 다시 뜬다                      ← 되돌릴 수 있는가
□ 다시 눌러 끄면 "꺼짐"으로 돌아온다               ← 두 방향
```

**★★ 셋째 줄이 판정이다** — 껐던 것이 실제로 돌아왔는가.

⚠️ **판정 전에 T-61 도 함께 걸린다** — L2가 안 뜨면 *"이 티켓이 실패한 것"* 과
*"그 밤이 공강 전날이라 안 뜬 것"* 이 화면에서 같아 보인다. **수업이 있는 날 밤에 잰다.**
