# HANDOFF 2026-07-31 — Claude 한도 소진 기간의 임시 운영

Cowork(설계·검토)와 Claude Code(구현 감독·검증)가 **한도 소진으로 잠시 빠진다.**
그동안 Codex가 두 자리를 겸한다. 이 문서는 그 기간에만 유효하고, 한도가 돌아오면 폐기한다.

---

## 1. 겸임하되, 경계는 그대로다

빠진 층의 **권한을 물려받는 것이 아니라, 그 층의 일이 멈추는 것**이다.

| 그대로 | 멈춘다 |
|---|---|
| 티켓에 적힌 구현 · verify · commit · push | 새 설계 판단 · ADR 작성 |
| `STATE.md` · `APP-BUILD.md` 갱신 | 설계 문서 · `APP-PLAN` · `APP-ADR` 수정 |
| 미리 발행된 티켓 소화 | **새 티켓 발행** |

**위임 금지 영역은 여전히 금지다**(`AGENT-CHAIN.md` §4) —
DB 트리거 · `migrations/*.sql` · 귀속일 계산 · Guard 발동 경로 · `wrangler.toml`.
Claude Code가 없다는 것은 그 영역을 Codex가 맡는다는 뜻이 아니라, **그 일이 대기한다**는 뜻이다.

## 2. 검토를 잃지 않는 법 — 세션을 나눈다

이 체인이 지키려던 것 하나가 **"구현자가 자기 검사를 통과시킨다"를 막는 것**이었다
(T-01에서 실제로 일어났다 — 검사가 하드코딩과 구별되지 않았다).

Claude Code가 빠지면 그 관문이 사라진다. 대신 **세션을 나눈다**:

```
Codex CLI (구현 세션)   티켓대로 구현 → verify → 티켓의 §보고 작성. 커밋하지 않는다
        ↓
Codex 앱 (검토 세션)    같은 티켓을 읽고 diff를 대조 → §검토 작성
        ↓
사용자                  숫자 확인 → 승인 → 커밋·push 지시
```

같은 세션에서 자기 것을 검토하면 검토가 아니다. **구현 세션은 커밋하지 않는다** —
그것이 두 세션을 강제하는 유일한 장치다.

### 검토 세션이 볼 것 (`AGENT-CHAIN.md` §8)

1. **설계 위반** — 파생값 저장 · SQL이 `db/index.ts` 밖 · 트리거 우회 · 귀속일을 기기 날짜로
2. **함정 재발** — `scrollIntoView` · 전역 클래스명 · 색 리터럴 · `booted` 가드
3. **숫자의 의미** — **구현을 잘못했다면 이 검사가 빨간불이 되는가.** 아니면 숫자만 올린 것이다

3번이 가장 무겁다. 통과 개수가 늘었다는 것만으로 승인하지 않는다.

### 구현 세션 (Codex CLI)

```

- 커밋하지 않는다. 검토 세션이 따로 본다
- 끝나면 티켓 파일의 §보고 절을 채운다

### 검토 세션 (Codex 앱)

```

1. 설계 위반 (파생값 저장 · db/index.ts 밖 SQL · 트리거 우회 · 귀속일)
2. 함정 재발 (CLAUDE.md 함정 목록 — 특히 전역 클래스명, 세 번 물렸다)

티켓 파일에 §검토 절을 쓰고, 통과면 사용자에게 승인을 요청해라.

## 6. 판단이 필요해지면

**고치지 말고 적는다.** 해당 티켓 파일에 `## Cowork 대기` 절을 만들고 무엇이 왜 막혔는지 쓴다.

지금 이미 대기 중인 것:

- `AI_TIMEOUT_MS`(8초) 검사 — 타임아웃 분기만 별도 회귀할 여지. 8초를 감수할지, 상수를 주입 가능하게 할지
- **Guard 기기 코드에 검사 러너가 없다** — `GuardWatch`·`GuardVerify`·`GuardRecheck`가 전부 실측에만
  의존한다. 셋의 핵심 로직(시간 계산·상한·창 판정)은 Android 의존이 없는 순수 함수라 JVM 단위 검사를
  붙일 수 있다. **지금 하지 않는다** — 실측 대기가 넷 쌓인 상태에서 검사 인프라를 새로 까는 것은 순서가 아니다
- `README0722.md` 소유권 — 소유권 표에 없는 파일
- **T-08 개정판** — 하향 제거 · 표시+상향만. Cowork가 써야 재개된다
- **T-10 모드 하향 서버 계약** — ADR-019 부수 규칙 1·2 강제. 위임 금지 영역
