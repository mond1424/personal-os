## 1부 — 침범 셀

### 증상

> 침범해서 뜨는 지난/다음 달 셀의 숫자는 이번 달에 비해 연하게 보이나
> **'기간'이 침범한 경우 색이 탁해지지 않음.** 전체를 덮는 탁한 형광펜 레이어를 추가해야 할 듯.
> 그리고 침범하는 셀 더 세게 가려야 함

**날짜 숫자만 연해지고 기간 밴드·일정·할 일은 그대로**라 이번 달 경계가 안 읽힌다.

### 방향 — 셀 전체를 덮는다

개별 요소마다 색을 낮추는 것이 아니라 **셀 위에 레이어 하나**를 얹는다.

- 요소가 늘 때마다 색을 또 낮춰야 하는 것을 피한다 —
  memo·기간·디데이가 이미 셀에 들어왔고 앞으로 더 는다
- 레이어는 **배경색 계열**이어야 한다. 어두운 오버레이를 쓰면 다크 모드에서 반대가 된다
- 지금의 "숫자만 연하게"는 **레이어로 대체하거나 함께 둔다** — 어느 쪽이든 결과가 더 뚜렷하면 된다

**색은 CSS 변수만.** 다크 대응은 항상 짝(`[data-theme="dark"]` + `@media prefers-color-scheme:dark`) — 함정 5.

### 넘치지 않게

침범 셀도 **누르면 그 날짜가 열린다**(다른 달로 이동). 그 동작을 막지 않는다.
`pointer-events`를 건드리면 안 된다 — 레이어는 순수 시각이다.

## 2부 — 터치 피드백

### 요구

> 터치한 박스 영역에 시각적 피드백. **라이트 모드에서는 어두운 피드백, 다크 모드에서는 밝은 색.**

**방향이 반대**라는 것이 이 항목의 전부다. 변수 짝으로 둔다 —
한 변수에 색을 넣고 다크에서 뒤집는 것이 아니라, `--press` 하나가 각 테마에서 다른 값을 갖는다.

### 어디에

누를 수 있는 것 전부가 아니라 **박스 영역**부터:

```
캘린더 셀 · 할 일 행 · 일정 행 · Me 섹션 항목 · 세그먼트
```

`nav` 버튼과 FAB은 이미 자기 상태 표시가 있다 — 중복을 만들지 않는다.

### 스와이프를 방해하지 않는다

**이것이 이 조각의 함정이다.** 탭 전환·캘린더 넘기기가 스와이프인데,
손가락이 지나가는 동안 피드백이 깜빡이면 성가시다.

- `:active`만으로는 스크롤·스와이프 중에도 붙는다
- **누르고 있는 동안만** 보이고, 손가락이 움직이기 시작하면 사라져야 한다
- `dragBlockUntil`·`AXIS_LOCK` 같은 기존 제스처 상수를 **건드리지 않는다** — 함정 2·4

기존 제스처 코드가 이미 "가로 이동 중"을 알고 있다. 그 신호를 읽는다.

## 금지

| 하지 말 것 | 왜 |
|---|---|
| 색 리터럴 | CSS 변수만. 다크 짝 필수 — 함정 5 |
| 침범 셀의 `pointer-events` 조정 | 눌러서 그 달로 가는 동작이 죽는다 |
| 제스처 상수(`dragBlockUntil`·`AXIS_LOCK`·`FLICK_V`) 수정 | 함정 2·4. 여기는 표시만 |
| `:active` 하나로 끝내기 | 스와이프 중에 깜빡인다 |
| 짧고 일반적인 새 클래스명 | 전역 충돌 **세 번**. 접두사(`.cal-dim-…` · `.press-…`) |
| `scrollIntoView` | 함정 1 |
| `booted` 가드 제거 | 함정 4 |

**검사가 잡는 것과 못 잡는 것을 나눈다.**

검사(구조):

1. 침범 셀에 **덮는 레이어가 붙는다** — 이번 달 셀에는 안 붙는다
2. 침범 셀을 눌러도 **그 달로 이동한다** (`pointer-events`를 안 죽였다)
3. 박스를 누르면 press 클래스가 붙고, **떼면 사라진다**
4. **가로로 움직이면 press가 떨어진다** — 스와이프 중 깜빡임 방지.
   이것이 `:active` 하나로 끝낸 구현에서 빨간불이 된다

실측(시각) — 검사로 대체 불가:

```
□ 침범 셀이 이번 달과 확실히 구별된다 (기간 밴드가 침범한 경우 포함)
□ 라이트에서 어둡게 · 다크에서 밝게 눌린다
□ 스와이프할 때 피드백이 깜빡이지 않는다
```

**4번이 이 티켓의 덫이다.** 1·2·3은 `:active` 한 줄로도 통과한다.


- `adb start-server`를 먼저 부르고 **그것에만** 넉넉한 상한(15초)
