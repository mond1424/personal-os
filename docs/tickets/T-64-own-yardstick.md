## 무엇이 어긋났나 — 규칙을 발행한 세션에 같은 것이 이미 있었다

`test/front.mjs` T-53의 마지막 검사:

```js
ok("★ 네이티브가 없으면 아무 말도 안 한다 — 'off'는 'ok'와 화면에서 같고 기록에서 다르다",
  t53Bar.dataset.state === "off" && t53Bar.style.display === "none"
  && t53Bar.dataset.state !== t53Synced.state          // ← 남의 관측값
  && t53Bar.style.display === t53Synced.display);      // ← 남의 관측값
```

**`t53Synced`는 검사 ④가 관측한 값이다.** 이 검사가 지는 것은 *"네이티브 없음이 조용한가"*
하나인데, **④의 대상이 흔들리면 이쪽도 함께 빨간불이 된다.**

⚠️ **T-59에서 같은 모양을 베껴 썼다가 실제로 물렸다** — 변이 M7(*정상에도 행동을 붙인다*)이
`t59Ok.display`를 `flex`로 만들자 **`off` 검사까지 죽었고**, 그 검사는 그 변이가 도는 동안
**자기 몫을 한 번도 못 셌다.** T-59 쪽은 계약값 비교로 고쳤고 **이쪽은 원본이라 남았다.**

## ★ 무엇이 계약이고 무엇이 관측인가

```
계약   구현이 지키기로 한 값        "off" · "ok" · "none"      ← 검사가 알아야 할 것
관측   다른 검사가 그때 본 값        t53Synced.state · .display  ← 남의 것
```

**같은 값이라도 출처가 다르다.** 지금은 우연히 같지만, `ok`가 틀리는 순간
**두 검사가 한 결함을 두 번 세고 아무도 자기 것을 안 센다.**

## 할 일 — 자를 바꾼다. 세는 것은 그대로다

```
지금   off.display === t53Synced.display        남이 그때 본 값
바꿈   off.display === "none"                   계약
```

⚠️ **④는 이미 `t53Synced.state === "ok" && t53Synced.display === "none"` 을 계약값으로 센다.**
**관계는 두 검사가 한 끝씩 잡는다** — 한 검사가 양쪽을 다 보려 하면 남의 몫까지 지게 된다.

### ★ 검사 이름이 세는 것과 어긋나면 이름을 고친다

지금 이름은 *"'ok'와 화면에서 같고 기록에서 다르다"* 인데, **자를 바꾸면 이 검사는 `ok`를
직접 보지 않는다.** 세는 것을 말하는 이름으로 바꾼다 —
⚠️ **관계를 이름에 남기고 싶으면 짝 검사를 주석으로 가리킨다**(어느 검사가 반대 끝인지).
**세지 않는 것을 이름이 주장하면, 그것이 다음 사람에게는 계약으로 읽힌다.**

## 범위

```
test/front.mjs      T-53 마지막 검사 하나
```

⚠️ **`public/`·`src/`·`android/` 를 열지 마라.** 구현은 옳다 — **자가 틀렸다.**
⚠️ **④를 고치지 마라.** 이미 계약값을 본다.

## 금지

| 하지 말 것 | 왜 |
|---|---|
| 구현을 고치기 | 결함은 검사에 있다. 구현이 바뀌면 이 티켓의 증거가 사라진다 |
| 검사를 지우기 | *"네이티브 없음이 조용한가"* 는 **아무도 대신 안 센다** |
| `t53Synced` 자체를 없애기 | ④가 쓴다 |
| 다른 검사도 같이 고치기 | §보고에 **이름만** 올린다. 아래 §훑기 |
| 세지 않는 관계를 이름에 남기기 | 다음 사람이 계약으로 읽는다 |

## 완료 조건

```
typecheck 통과 · smoke(변화 없음) · front(변화 없음 또는 +1) · 실패 0 · verify exit 0
```

⚠️ **기준선은 `STATE.md` §기준선이 원장이다.**
⚠️ **`smoke`가 움직이면 범위 밖을 건드린 것이다** — 멈추고 보고한다.

**변이 — 이 티켓의 판정은 검사 목록이 아니라 변이표다**

고치기 **전과 후에 같은 둘**을 돌리고, **표가 달라지는 것**을 보인다.

```
M1 loadCalStatus 가 정상(ok)에도 바를 띄운다
     전   ④ + off 검사   ← 물린 자리. off 는 여전히 조용한데 죽는다
     후   ★ ④만
M2 loadCalStatus 가 네이티브 없음(off)에도 바를 띄운다
     전   off 검사만
     후   off 검사만     ← 안 움직여야 한다. 관측력을 안 잃었는가
```

**M1의 전↔후가 이 티켓의 전부다.** M2는 그 짝이다 —
⚠️ **자를 바꾸다 세는 것까지 줄이면 M2가 조용해진다.** 그때는 고친 것이 아니라 지운 것이다.

⚠️ **변이가 러너를 죽이면 그 줄은 판정이 아니다**(`AGENT-CHAIN` §8). 요약 줄이 나온 것만 적는다.

## 훑기 — 찾되 고치지 않는다

`test/front.mjs`·`test/smoke.ts`에 **같은 모양이 또 있는지** 한 번 훑는다:
**다른 검사가 만든 변수를 기대값 자리에 쓰는 곳.**

```
있으면   §보고에 파일·줄·검사 이름만 적는다        ← 다음 티켓의 재료
없으면   "없다"고 적는다                          ← 그것도 결과다
```

⚠️ **고치지 마라.** T-59가 하나를 고치고 이 하나를 남긴 이유가 그것이다 —
**고치면 저쪽 변이를 다시 돌려야 하고, 그 순간 티켓이 둘이 된다.**

## 확인 절차 (사용자)

**없다.** 검사만 바뀐다 — deploy·APK·재설치 어느 것도 필요 없다.
⚠️ **이것이 지금 이 티켓을 고른 이유다** — 실측 다섯이 밤을 기다리는 동안 **막히지 않는 일**이다.

### 무엇을 바꿨나 — 네 조각 중 둘

`test/front.mjs` T-53 마지막 검사 하나. **`public/`·`src/`·`android/`를 고치지 않았다**(변이용 임시
편집은 매번 `git checkout -- public/app.js`로 되돌렸고, 최종 트리에 `public/` 변경은 없다).

```
전   state === "off" && display === "none"
     && state !== t53Synced.state        ← 남의 관측값
     && display === t53Synced.display    ← 남의 관측값 · 위 display 검사와 같은 말이었다
후   state === "off" && display === "none"
     && state !== "ok"                   ← 계약값 (자매 T-59가 쓰는 것과 같은 모양)
```

넷째 조각은 **지운 것이 아니라 둘째와 같은 말이었다** — `t53Synced.display`가 `"none"`이라서
성립하던 식이고, 둘째가 이미 계약값으로 그것을 센다. 셋째는 계약값(`!== "ok"`)으로 갈았다.
**세는 것은 그대로다**(아래 M2가 그 증거다).

**이름을 고쳤다** — 전 *"'off'는 'ok'와 화면에서 같고 기록에서 다르다"* 는 이 검사가 더는 보지
않는 `ok`를 주장한다. 후 *"화면은 조용하고 기록에만 'off'로 남는다"* (자매 T-59와 같은 문장).
**관계는 주석으로 남겼다** — 반대 끝(`ok`가 안 뜬다)은 위 ④가 계약값으로 센다고 가리킨다.

### 변이표 — 전 ↔ 후

변이 자리는 `public/app.js:901` 하나다(`bar.style.display = CAL_ACT[v.state] ? "flex" : "none"`).

| 변이 | 전 | 후 |
|---|---|---|
| **M1** 정상(`ok`)에도 바를 띄운다 | ④ + off 검사 (**435/2**) | ★ **④만** (436/1) |
| **M2** 네이티브 없음(`off`)에도 바를 띄운다 | off 검사만 (436/1) | off 검사만 (436/1) |

**M1이 이 티켓의 전부다.** 전에는 `④ ★ 동기화 실패도 뜨고…`와 `★ 네이티브가 없으면…`이
**함께** 빨간불이 됐다 — off 검사는 여전히 조용한데 남의 자가 흔들려서 죽은 것이다.
후에는 ④만 죽는다. **M2는 안 움직였다** — 자를 바꾸면서 관측력을 잃지 않았다.

⚠️ **둘 다 러너가 살아서 요약 줄이 나왔다**(`AGENT-CHAIN` §8). 넷 다 판정으로 센다.
